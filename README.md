# 🧘‍♂ Mixed Messages

A small Node.js program that generates randomized coaching-style messages, including:

1. A quote to reflect on  
2. A core principle  
3. A suggested daily practice  

Each run produces a unique combination, styled with simple ASCII formatting. The messages draw from my early training in transformative communication and coaching.

## 🎯 Purpose

This was one of my first portfolio projects in the Codecademy Full-Stack Engineer path — a practice in foundational JavaScript, Git, and local development.

This project is also the first time I brought my coaching background into software — a theme I intend to revisit in deeper ways later on.

## 🛠️ Tech Used

- JavaScript (Node.js)
- Git & CLI
- Arrays, strings, and `Date` objects

## ▶️ How to Run

Run `main.js` using Node.js in your terminal. Each execution will print a fresh message to the console.
